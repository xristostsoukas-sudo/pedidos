💰 Atualização em Massa de Preços

Atualize os preços de todos os produtos ativos de uma só vez. Escolha a porcentagem de aumento ou redução.

⚠️ Atenção!

Esta operação irá alterar os preços de TODOS os produtos ativos no banco de dados.

  • Use valores positivos para AUMENTAR (ex: 5 para +5%)
  • Use valores negativos para REDUZIR (ex: -3 para -3%)
  • Produtos com preço zero NÃO serão atualizados
  • Não há como reverter automaticamente
Exemplos: 5 = aumentar 5% | -3 = reduzir 3% | 10 = aumentar 10%
